# Spec Delta

## MODIFIED Requirements

### Requirement: Шкала показателей
Интерфейс SHALL окрашивать значения rating, K/D, ADR и KAST по фиксированным порогам, одинаковым на всех
экранах: rating ниже 0.95 — «плохо», выше 1.25 — «хорошо»; K/D ниже 0.85 и выше 1.15; ADR ниже 60 и выше 90;
KAST ниже 65% и выше 75%. Граничные значения относятся к «средне». Остальные показатели не окрашиваются. Уровень
MUST отличаться не только оттенком.

#### Scenario: Хороший rating
- **WHEN** у игрока rating 1.51
- **THEN** значение показано как «хорошо»

#### Scenario: Граница порога
- **WHEN** у игрока K/D ровно 0.85 и ADR ровно 90
- **THEN** оба значения показаны как «средне»

#### Scenario: Rating у среднего игрока компании
- **WHEN** у игрока rating 1.08
- **THEN** значение показано как «средне»

#### Scenario: Неокрашиваемый показатель
- **WHEN** у игрока HS% равен 59%
- **THEN** значение показано обычным цветом текста
