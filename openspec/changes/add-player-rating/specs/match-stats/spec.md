# Spec Delta

## MODIFIED Requirements

### Requirement: Rating
Система SHALL считать rating игрока по восстановленной формуле HLTV Rating 2.0 на основе KAST, убийств, смертей, ассистов и урона за раунд. Rating по нескольким матчам SHALL считаться по сумме счётчиков, так что он равен среднему rating матчей, взвешенному по раундам.

#### Scenario: Средний игрок
- **WHEN** у игрока KAST 70%, 0.65 убийства, 0.68 смерти, 0.13 ассиста и 70 урона за раунд
- **THEN** rating равен 0.0073·70 + 0.3591·0.65 − 0.5329·0.68 + 0.2372·(2.13·0.65 + 0.42·0.13 − 0.41) + 0.0032·70 + 0.1587 ≈ 1.01

#### Scenario: Без раундов
- **WHEN** у игрока ноль раундов
- **THEN** rating равен 0
