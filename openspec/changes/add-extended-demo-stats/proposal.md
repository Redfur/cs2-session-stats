# Proposal

## Why

Дополнительная статистика профиля должна объяснять игру человека: клатчи, размены, оружие, стрельбу и использование гранат. Сейчас парсер сохраняет достаточно данных для базового scoreboard, но не для этих разделов. Если расширять только интерфейс, отсутствующие данные придётся подменять нулями или несопоставимыми показателями внешних платформ.

Статус: проект для технического ревью, без реализации. Проверен текущий код main 10 октября 2026: `internal/parser`, `internal/stats`, `internal/store`, обработка и пересчёт матчей; используется demoinfocs v5.2.0. Точные определения новых вычисляемых метрик ниже — предложения для согласования, а не утверждённая методика Scope/FastCup.

## What Changes

- Расширить сбор событий и сохраняемые результаты: попытки и победы в клатчах 1vN, размены, статистика оружия, исходные данные стрельбы и utility.
- Для Utility подготовить пять согласованных величин **в среднем за карту**: урон HE, количество ослеплённых игроков, секунды ослепления, использованные смоки, урон Molotov/Incendiary. Методика ослеплений и объединение огня требуют ревью.
- Ввести версионированные определения и покрытие каждой группы метрик: известный ноль, частичные и отсутствующие данные различаются.
- Выдавать расширение через API профиля и матча; агрегировать исходные суммы и знаменатели, безопасно пересчитывать старые демки.
- Проверить извлечение спорных данных на контрольных демках до включения соответствующих метрик. Не обещать эквивалентность Accuracy, FBA, TTK/TTD из Scope.

## Capabilities

### New Capabilities

- `extended-demo-stats`: воспроизводимый сбор и выдача расширенных показателей из демок с явными определениями и покрытием.

### Modified Capabilities

Нет намеренной замены существующих требований. Сохраняются текущие базовые формулы и жизненный цикл обработки матчей; новая группа подключается к ним аддитивно.

## Impact

При реализации: модель и события `internal/parser`, расчёты `internal/stats`, SQLite и миграции `internal/store`, воркер/версия обработки, API и типы клиента. Потребуются контрольные демки и пересчёт старых результатов.

Этот PR содержит только документы. Вёрстка дополнительного экрана, OVR и атрибуты карточки, новые рейтинги, балансировка команд, сбор из закрытых API и замена исторических источников не входят. Личные дуэли описаны отдельно в [PR #1](https://github.com/Redfur/cs2-session-stats/pull/1); изменения независимы и не дублируют его требования.
