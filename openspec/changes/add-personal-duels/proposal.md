# Proposal

## Why

В профиле друга хочется увидеть, кого он чаще всего убивает и от кого чаще всего погибает. Общие K/D и рейтинг этого не показывают. В демо уже доступны участники убийств, но парные счётчики не сохраняются.

Статус: проект спецификации для ревью, без реализации. Основа анализа — main `0f2539b9697162db0b9871ac1a90e7bf9ee758a0`. Продуктовый объём уточнён 7 октября 2026: два компактных показателя в дополнительной статистике; полная таблица соперников не требуется.

## What Changes

- Сохранять личные убийства между противниками по SteamID64 для каждого матча.
- Агрегировать оба направления пары за выбранный период профиля.
- Показывать «Чаще всего убивает» и «Чаще всего погибает от»: ник, личный счёт убил/погиб и количество карт против друг друга.
- Сохранять всех соперников при равенстве максимума; один соперник может соответствовать обоим показателям.
- Различать отсутствие расчёта, частичное покрытие и известный ноль; поддержать безопасный пересчёт старых матчей.

Не входит: полный список соперников в UI, автоматический выбор лучшего/худшего по проценту, вероятности победы, изменение рейтинга/OVR, балансировка, клатчи, redesign профиля целиком, импорт исторических таблиц FastCup/Scope. Расчёт из демо не объявляется идентичным матрицам FastCup и не заменяет источник в другом проекте без отдельного решения.

## Capabilities

### New Capabilities

- `personal-duels`: накопленные парные убийства и два компактных показателя в профиле.

### Modified Capabilities

Нет замены существующих требований: новый блок использует фильтр периода и жизненный цикл пересчёта из существующих capabilities.

## Impact

При реализации затрагиваются `internal/stats`, сохранение результатов в `internal/store`, версия обработки и воркер, API профиля и `web/src/pages/PlayerPage.tsx`. Потребуются миграция и пересчёт демок. Этот PR добавляет только документы; технические варианты вынесены в `design.md` для ревью разработчиком.
