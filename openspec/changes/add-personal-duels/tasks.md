## 2. Агрегация и API

- [ ] 2.1 Запросы store: дуэли матча, сумма по сессии только по матчам, где пара была соперниками, сумма за период профиля с числом карт и сессий против. Покрытие считается по `has_result = 1 AND result_version >= 2`. Тесты: 3:1 + 0:0 + 2:4 = 5:5 на трёх картах, союзники в одном матче не учитываются, даты включительно по дате сессии.
- [ ] 2.2 `GET /api/matches/{id}/duels`, `GET /api/sessions/{id}/duels`, `GET /api/players/{steamId}/duels` по design.md: статусы, `share` из сумм (1:0 + 1:8 → 0.2, при 0:0 — `null`), SteamID строками, ник соперника из последнего матча. Тесты api: равные максимумы, один соперник в обоих показателях, все пары 0:0, `partial`/`unavailable`/`no_matches`, ошибка сочетания дат и сессий, 404 для неизвестных матча, сессии и игрока.
