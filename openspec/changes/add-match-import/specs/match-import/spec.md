# Spec Delta

## Purpose

Импорт матчей по ссылке на страницу матча платформы: сервис сам находит и в фоне скачивает демки матча, включая все карты серии Bo3/Bo5, и добавляет их в сессию как обычные загрузки.

## ADDED Requirements

### Requirement: Добавление матча по ссылке
Система SHALL принимать в существующую сессию ссылку на страницу матча и сразу отвечать созданной загрузкой в статусе «в очереди», не дожидаясь скачивания. Ссылка разбирается при добавлении. Пробелы по краям, протокол `http`, `www.`, языковой префикс пути, параметры и фрагмент адреса MUST NOT мешать распознаванию.

#### Scenario: Ссылка FastCup
- **WHEN** пользователь добавляет в сессию `https://cs2.fastcup.net/matches/27802385`
- **THEN** создаётся загрузка FastCup с номером матча 27802385 в статусе «в очереди», и ответ приходит до начала скачивания

#### Scenario: Ссылка Cybershoke с языком
- **WHEN** пользователь добавляет `https://cybershoke.net/ru/match/12578063?tab=stats`
- **THEN** создаётся загрузка Cybershoke с номером матча 12578063

#### Scenario: Несуществующая сессия
- **WHEN** ссылка добавляется в неизвестную сессию
- **THEN** запрос отклоняется с ошибкой «не найдено», загрузка не создаётся

### Requirement: Поддерживаемые платформы
Система SHALL принимать только ссылки на страницы матчей FastCup (`cs2.fastcup.net/matches/{номер}`) и Cybershoke (`cybershoke.net/match/{номер}`). Другие сайты, другие страницы этих сайтов и прямые ссылки на файлы MUST отклоняться сразу, с ошибкой, в которой приведены примеры допустимых ссылок.

#### Scenario: Чужой сайт
- **WHEN** пользователь добавляет `https://example.com/match/1`
- **THEN** запрос отклоняется с ошибкой и примерами ссылок FastCup и Cybershoke, загрузка не создаётся

#### Scenario: Не страница матча
- **WHEN** пользователь добавляет `https://cs2.fastcup.net/id1234`
- **THEN** запрос отклоняется с той же ошибкой

#### Scenario: Faceit пока не поддерживается
- **WHEN** пользователь добавляет ссылку на комнату Faceit
- **THEN** запрос отклоняется с ошибкой о неподдерживаемом сайте

### Requirement: Повторная ссылка на тот же матч
Система MUST NOT создавать вторую загрузку матча платформы, который уже скачивается или из которого есть матч в любой сессии. Ответ содержит сессию, где этот матч уже есть. Если у этого матча платформы есть загрузка с ошибкой в той же сессии, повторная ссылка ставит её на повтор. Если матчи из прежней загрузки удалены, ссылку можно добавить снова.

#### Scenario: Матч уже скачивается
- **WHEN** ссылка на матч добавлена, скачивание ещё идёт, и пользователь добавляет её снова в эту или другую сессию
- **THEN** запрос отклоняется с ошибкой «уже скачивается» и ссылкой на сессию этой загрузки

#### Scenario: Матч уже загружен
- **WHEN** из ссылки уже создан матч, и пользователь добавляет ту же ссылку
- **THEN** запрос отклоняется с ошибкой «уже загружен» и ссылками на сессию и матч

#### Scenario: Загрузка с ошибкой
- **WHEN** в сессии есть загрузка этого матча со статусом «ошибка», и пользователь добавляет ссылку снова
- **THEN** новая загрузка не создаётся, прежняя ставится в очередь заново

#### Scenario: Матчи удалены
- **WHEN** все матчи, созданные из ссылки, удалены, и пользователь добавляет ссылку снова
- **THEN** создаётся новая загрузка в статусе «в очереди»

### Requirement: Поиск демок матча
Система SHALL сама находить адреса демок по номеру матча через данные платформы. Если демку получить нельзя, загрузка MUST получать статус «ошибка» с понятной причиной: матч не найден, матч ещё не закончен, демка ещё не готова, демка удалена платформой по сроку хранения, платформа недоступна или изменила формат ответа. Во всех случаях текст предлагает загрузить файл вручную.

#### Scenario: Матч не закончен
- **WHEN** добавлена ссылка на матч, который ещё идёт
- **THEN** загрузка получает статус «ошибка» с текстом «матч ещё не закончен»

#### Scenario: Демка удалена по сроку
- **WHEN** добавлена ссылка на матч FastCup, срок хранения демки которого истёк
- **THEN** загрузка получает статус «ошибка» с текстом о том, что платформа удалила демку, и советом загрузить файл вручную, если он сохранён

#### Scenario: Платформа изменила API
- **WHEN** платформа отвечает ошибкой или ответом неожиданного формата
- **THEN** загрузка получает статус «ошибка» с текстом о том, что получить демку с платформы не удалось, и советом загрузить файл вручную

### Requirement: Серии Bo3 и Bo5
Для серии система SHALL создавать отдельный матч из каждой сыгранной карты в порядке карт серии. Несыгранные карты серии пропускаются. Каждый файл демки проходит тот же приём, что и ручная загрузка: форматы, лимит размера, распаковка и дедупликация.

#### Scenario: Bo3 Cybershoke 2:0
- **WHEN** добавлена ссылка на Bo3 Cybershoke, закончившуюся 2:0, и платформа отдаёт один архив с демками `map1` и `map2`
- **THEN** в сессии появляются два матча, сначала из `map1`, затем из `map2`

#### Scenario: Bo3 FastCup
- **WHEN** добавлена ссылка на Bo3 FastCup из трёх сыгранных карт
- **THEN** в сессии появляются три матча в порядке номеров карт

#### Scenario: Одна карта уже загружена
- **WHEN** демка второй карты серии уже была загружена вручную
- **THEN** вторая карта отмечена в загрузке как «уже загружена» со ссылкой на существующий матч, остальные карты становятся новыми матчами

### Requirement: Фоновое скачивание
Система SHALL скачивать загрузки в фоне по одной, в порядке добавления. Статусы загрузки: «в очереди» → «скачивается» → «готово» или «ошибка». Матч создаётся только после скачивания и проверки его демки, получает следующий номер в сессии и дальше обрабатывается как загруженный вручную.

#### Scenario: Порядок загрузок
- **WHEN** в сессию с двумя матчами подряд добавлены ссылки A (Bo1) и B (Bo1)
- **THEN** матч из A получает номер 3, матч из B — номер 4

#### Scenario: Ручная загрузка во время скачивания
- **WHEN** пока скачивается ссылка A, пользователь загружает файл вручную
- **THEN** файл становится матчем сразу, а матч из A получает следующий номер после скачивания

#### Scenario: Успешная загрузка
- **WHEN** все демки загрузки скачаны и приняты
- **THEN** загрузка получает статус «готово», её матчи ставятся в обработку

### Requirement: Частичный результат загрузки
Если какую-то карту загрузки скачать или принять не удалось, загрузка SHALL получать статус «ошибка» с текстом причины. Матчи из уже принятых карт сохраняются. Для каждой карты загрузка показывает результат: принята (со ссылкой на матч), уже загружена (со ссылкой на существующий матч) или ошибка.

#### Scenario: Ошибка второй карты
- **WHEN** в Bo3 первая карта принята, а демка второй превышает лимит размера
- **THEN** загрузка получает статус «ошибка» с текстом о превышении размера, матч из первой карты остаётся в сессии

### Requirement: Прогресс скачивания
Пока загрузка скачивается, система SHALL показывать объём уже скачанных данных, а если платформа сообщает размер файла, ещё полный объём и процент. Прогресс обновляется без перезагрузки страницы.

#### Scenario: Размер известен
- **WHEN** скачано 196 МБ файла размером 392 МБ
- **THEN** у загрузки показано 50% и «196 из 392 МБ»

#### Scenario: Размер неизвестен
- **WHEN** платформа не сообщила размер файла, и скачано 120 МБ
- **THEN** у загрузки показано «120 МБ» без процента

### Requirement: Повтор, отмена и удаление загрузки
Система SHALL позволять поставить загрузку со статусом «ошибка» на повтор. Повтор начинается с поиска демок заново, уже принятые карты отмечаются как «уже загружена». Система SHALL позволять удалить загрузку в любом статусе. Удаление прерывает идущее скачивание. Созданные из загрузки матчи при удалении загрузки остаются.

#### Scenario: Повтор после «демка ещё не готова»
- **WHEN** загрузка получила ошибку «демка ещё не готова», и позже пользователь нажимает «Повторить»
- **THEN** загрузка снова встаёт в очередь и, если демка готова, завершается созданием матча

#### Scenario: Отмена скачивания
- **WHEN** пользователь удаляет загрузку, пока идёт скачивание
- **THEN** скачивание прерывается, временные файлы удаляются, матч из незаконченной карты не создаётся

#### Scenario: Удаление завершённой загрузки
- **WHEN** пользователь убирает из списка загрузку со статусом «ошибка», из которой уже создан один матч
- **THEN** загрузка исчезает из списка, матч остаётся в сессии

### Requirement: Загрузки при удалении сессии
При удалении сессии система SHALL удалять все её загрузки и прерывать идущее скачивание.

#### Scenario: Удаление сессии во время скачивания
- **WHEN** пользователь удаляет сессию, загрузка которой скачивается
- **THEN** скачивание прерывается, загрузки сессии удаляются, матчи из неё не создаются

### Requirement: Перезапуск сервиса
Загрузки SHALL переживать перезапуск сервиса. Загрузки «в очереди» сохраняются. Прерванное скачивание после старта ставится в очередь и начинается заново.

#### Scenario: Остановка во время скачивания
- **WHEN** сервис остановлен, пока загрузка скачивалась
- **THEN** после старта загрузка снова встаёт в очередь, частично скачанный файл не используется

### Requirement: Скачивание только с хостов платформ
Система MUST обращаться при импорте только к хостам поддерживаемых платформ (домены `fastcup.net`, `cybershoke.net` и их поддомены), в том числе при перенаправлениях. Скачанный объём MUST ограничиваться лимитом размера демки, превышение прерывает скачивание.

#### Scenario: Перенаправление на чужой хост
- **WHEN** адрес демки отвечает перенаправлением на хост вне списка платформ
- **THEN** скачивание прерывается, загрузка получает статус «ошибка»

#### Scenario: Слишком большой файл
- **WHEN** скачиваемый файл превышает лимит размера демки
- **THEN** скачивание прерывается, временный файл удаляется, загрузка получает статус «ошибка» о превышении размера

### Requirement: Ссылка на матч в интерфейсе
На странице сессии рядом с зоной загрузки файлов интерфейс SHALL показывать поле «Ссылка на матч» с кнопкой добавления, доступное с клавиатуры (Enter). Ошибка добавления показывается под полем, введённая ссылка при этом сохраняется. После успешного добавления поле очищается.

#### Scenario: Неподдерживаемая ссылка
- **WHEN** пользователь вставляет ссылку на чужой сайт и нажимает Enter
- **THEN** под полем показана ошибка с примерами допустимых ссылок, ссылка остаётся в поле

#### Scenario: Уже загружен
- **WHEN** сервер отвечает, что матч уже загружен
- **THEN** под полем показана ошибка со ссылкой на сессию, где он есть

### Requirement: Список загрузок в интерфейсе
Интерфейс SHALL показывать на странице сессии загрузки в статусах «в очереди», «скачивается» и «ошибка», а также завершённые загрузки, в которых не все карты стали новыми матчами. Строка показывает платформу, номер матча, статус бейджем, прогресс, текст ошибки, результат по картам и действия «Повторить», «Отменить» или «Убрать». Пока есть загрузки в работе, страница обновляет их сама.

#### Scenario: Скачивание завершилось
- **WHEN** загрузка Bo1 скачалась и матч принят
- **THEN** загрузка пропадает из списка, а матч появляется в таблице матчей со статусом «В очереди» без перезагрузки страницы

#### Scenario: Матч уже был загружен файлом
- **WHEN** загрузка завершилась, а её единственная демка оказалась уже загруженной
- **THEN** загрузка остаётся в списке с пометкой «уже загружен» и ссылкой на матч, пока пользователь её не уберёт
