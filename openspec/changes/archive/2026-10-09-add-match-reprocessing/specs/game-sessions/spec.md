# Spec Delta

## MODIFIED Requirements

### Requirement: Сводная статистика игроков за сессию
Система SHALL показывать на странице сессии таблицу игроков, участвовавших хотя бы в одном матче сессии с посчитанным результатом, с агрегатами: число матчей, победы, K, D, A, K/D, ADR, HS%, KAST и средний rating. В агрегаты входят все матчи с результатом, включая пересчитываемые и матчи с неудачным пересчётом. Матчи без результата не входят.

#### Scenario: Агрегация по нескольким матчам
- **WHEN** игрок сыграл в сессии 2 матча: 20 раундов с суммарным уроном 1600 и 30 раундов с уроном 2400
- **THEN** ADR игрока за сессию равен (1600 + 2400) / (20 + 30) = 80

#### Scenario: Средневзвешенные проценты
- **WHEN** KAST и HS% считаются за сессию
- **THEN** они вычисляются по суммарным раундам и убийствам всех матчей, а не как среднее процентов

#### Scenario: Rating за сессию
- **WHEN** игрок сыграл несколько матчей
- **THEN** rating за сессию взвешивается по количеству раундов в каждом матче

#### Scenario: Неготовые матчи исключены
- **WHEN** в сессии один матч `done` и один `failed` при первой обработке (результата у него нет)
- **THEN** сводная таблица строится только по матчу `done`

#### Scenario: Матч в пересчёте или с неудачным пересчётом
- **WHEN** у матча есть результат, а сам он стоит в очереди на пересчёт или его пересчёт завершился ошибкой
- **THEN** его прежний результат входит в сводную таблицу

#### Scenario: Игрок идентифицируется по SteamID64
- **WHEN** игрок сменил ник между матчами
- **THEN** его статистика объединяется в одну строку, отображается ник из последнего по порядку матча
