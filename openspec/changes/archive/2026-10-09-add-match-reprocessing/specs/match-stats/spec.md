# Spec Delta

## MODIFIED Requirements

### Requirement: Просмотр матча
Система SHALL показывать страницу матча с картой, счётом, статусом обработки и scoreboard двух команд. Строки упорядочены по rating, для каждого игрока выводятся все показатели матча. Если у матча есть результат, scoreboard показывается при любом статусе вместе с пометкой о пересчёте или текстом ошибки.

#### Scenario: Матч обработан
- **WHEN** пользователь открывает матч в статусе `done`
- **THEN** он видит счёт и две таблицы игроков с показателями

#### Scenario: Матч с ошибкой
- **WHEN** пользователь открывает матч в статусе `failed`, у которого нет результата
- **THEN** он видит текст ошибки обработки вместо scoreboard

#### Scenario: Матч пересчитывается
- **WHEN** пользователь открывает матч с результатом в статусе `pending` или `parsing`
- **THEN** он видит прежние счёт и scoreboard с пометкой, что идёт пересчёт

#### Scenario: Пересчёт не удался
- **WHEN** пользователь открывает матч с результатом в статусе `failed`
- **THEN** он видит прежние счёт и scoreboard и текст ошибки последнего пересчёта
