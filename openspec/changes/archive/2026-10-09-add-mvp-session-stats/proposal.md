# Proposal

## Why

Компания друзей регулярно играет вечерами кастомные 5х5 матчи между собой на FastCup и Cybershoke.
Существующие сервисы (Leetify, scope.gg, csstats) считают статистику по всем матчам игрока и не умеют показывать итоги
конкретного игрового вечера «внутри компании». Нужен минимальный работающий инструмент: загрузил демки вечера →
получил сводную статистику по каждому матчу и по сессии в целом. Это MVP, на котором проверяем гипотезу и точность парсинга.

## What Changes

- Новый Go-сервис (один бинарь): HTTP API, фоновый воркер парсинга демок, хранение в SQLite, исходные демки на диске.
- Создание игровой сессии вручную: дата (по умолчанию сегодня) и опциональное название.
- Загрузка одной или нескольких демок в сессию (`.dem` и архивы `.gz`, `.bz2`, `.zst`, `.zip`), догрузка в существующую сессию,
  дедупликация по SHA-256, асинхронный парсинг со статусами `pending` / `parsing` / `done` / `failed`.
- Парсинг демки: карта, итоговый счёт, игроки (SteamID64, ник, сторона), количество раундов.
- Статистика игрока за матч: K/D/A, ADR, HS%, KAST, мульти-киллы (2K–5K), opening kills/deaths, rating (по формуле HLTV 1.0).
- Сводная статистика игроков за сессию (суммы и средние по всем матчам сессии).
- React-прототип из трёх страниц: список сессий (с созданием), страница сессии (загрузка демок, матчи, сводная таблица), страница матча (scoreboard).
- `Dockerfile` и `docker-compose.yml` для запуска одной командой.

Не входит (будущие changes): авторизация через Steam, группы, загрузка по ссылке, экономика/клатчи/трейды,
профиль игрока за всё время, синергия пар, балансировщик команд, 2D-реплей, удаление и редактирование матчей.

## Capabilities

### New Capabilities
- `game-sessions`: создание и просмотр игровых сессий, порядок матчей внутри сессии, сводная статистика игроков за сессию.
- `demo-ingestion`: загрузка файлов демок в сессию, распаковка, дедупликация, хранение и асинхронная обработка со статусами.
- `match-stats`: извлечение данных матча из демки и расчёт статистики игроков за матч; просмотр scoreboard матча.

## Impact

- Новый код: `cmd/cs2stats`, `internal/{parser,stats,store,api,ingest}`, `web/` (Vite + React + TS).
- Зависимости: `github.com/markus-wa/demoinfocs-golang/v5` (или актуальная мажорная версия), `modernc.org/sqlite`,
  `github.com/klauspost/compress/zstd`; фронт — `react`, `react-router`.
- Диск: исходные демки ~100–400 МБ каждая в `/data/demos`; БД `/data/cs2stats.db`.
- Внешних API и сетевых интеграций нет.
