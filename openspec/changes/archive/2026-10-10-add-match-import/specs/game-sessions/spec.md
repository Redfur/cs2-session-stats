# Spec Delta

## MODIFIED Requirements

### Requirement: Порядок матчей в сессии
Система SHALL упорядочивать матчи внутри сессии по порядку загрузки: в пределах одной загрузки — по порядку файлов, догруженные матчи идут после уже существующих. Исключение — матчи, добавленные по ссылке на матч платформы: их место определяется временем игры (требование «Место матча в сессии по времени игры» в `match-import`). Номера матчей сессии MUST идти подряд с 1: после удаления, перестановки или вставки матча они пересчитываются.

#### Scenario: Порядок при загрузке нескольких файлов
- **WHEN** в сессию за одну загрузку переданы файлы A, B, C
- **THEN** матчи сессии нумеруются 1 — A, 2 — B, 3 — C

#### Scenario: Догрузка в существующую сессию
- **WHEN** в сессию с матчами A, B догружается файл C
- **THEN** C получает номер 3

#### Scenario: Перенумерация после удаления
- **WHEN** из сессии с матчами 1 — A, 2 — B, 3 — C удалён матч B
- **THEN** матчи сессии нумеруются 1 — A, 2 — C, а следующий загруженный файл получает номер 3

#### Scenario: Вставка матча по ссылке
- **WHEN** в сессии матчи 1 — A и 2 — B добавлены по ссылкам и сыграны в 20:00 и 21:00, а затем по ссылке добавлен матч C, сыгранный в 20:30
- **THEN** матчи сессии нумеруются 1 — A, 2 — C, 3 — B
