# Spec Delta

## MODIFIED Requirements

### Requirement: Просмотр матча
Система SHALL показывать страницу матча с картой, счётом, статусом обработки и scoreboard двух команд. Строки по умолчанию упорядочены по rating, пользователь может отсортировать их по другой колонке. Для каждого игрока выводятся все показатели матча. Если у матча есть результат, scoreboard показывается при любом статусе вместе с пометкой о пересчёте или текстом ошибки. Страница показывает название сессии матча со ссылкой на неё и номер матча среди матчей сессии с переходом к предыдущему и следующему.

#### Scenario: Матч обработан
- **WHEN** пользователь открывает матч в статусе `done`
- **THEN** он видит счёт и две таблицы игроков с показателями

#### Scenario: Матч с ошибкой
- **WHEN** пользователь открывает матч в статусе `failed`, у которого нет результата
- **THEN** он видит текст ошибки обработки вместо scoreboard

#### Scenario: Матч пересчитывается
- **WHEN** пользователь открывает матч с результатом в статусе `pending` или `parsing`
- **THEN** он видит прежние счёт и scoreboard с пометкой, что идёт пересчёт

#### Scenario: Пересчёт не удался
- **WHEN** пользователь открывает матч с результатом в статусе `failed`
- **THEN** он видит прежние счёт и scoreboard и текст ошибки последнего пересчёта

#### Scenario: Переход к соседнему матчу
- **WHEN** пользователь открывает матч №2 сессии «fastcup-5-games» из 5 матчей
- **THEN** страница показывает «к сессии fastcup-5-games», «2 из 5» и ссылки на матчи №1 и №3

#### Scenario: Первый матч сессии
- **WHEN** пользователь открывает матч №1
- **THEN** переход к предыдущему матчу недоступен

## ADDED Requirements

### Requirement: Итог команды на странице матча
Страница матча SHALL показывать над таблицей каждой команды её название, исход матча для команды («Победа» или «Поражение», при ничьей — «Ничья») и суммы K, D, A игроков команды. В крупном счёте победившая сторона MUST выделяться не только цветом.

#### Scenario: Победа команды A
- **WHEN** матч закончился 13:10 в пользу команды A
- **THEN** у команды A показано «Победа», у команды B — «Поражение», рядом со счётом у стороны A — бейдж «Победа»

#### Scenario: Суммы команды
- **WHEN** игроки команды A сделали 28, 18, 19, 14 и 10 убийств
- **THEN** в шапке команды A указана сумма убийств 89
