# Proposal

## Why

Фронтенд сейчас уровня прототипа: голый HTML почти без стилей. Таблицы трудно читать, на телефоне страница
уезжает вбок, удаление подтверждается браузерным `confirm()`, а большие демки загружаются одним запросом без
понятного прогресса. В Claude Design подготовлены дизайн-система и макеты всех экранов
(https://claude.ai/artifact/RyiK38Ld5u2q9uQMxYhe6h). Их нужно перенести в код так, чтобы новые экраны и
графики потом собирались из готовых компонентов.

## What Changes

- Фронтенд переходит на Tailwind v4 с токенами из дизайна (`@theme`), Headless UI для диалогов, поповеров и
  радиогрупп, шрифты Manrope и JetBrains Mono самохостом через `@fontsource-variable`. Тема только тёмная.
- Появляется набор UI-компонентов: каркас с шапкой, заголовок страницы, карточка, кнопки, поля, бейджи
  статуса и исхода, счёт, ячейка метрики, таблица статистики, диалог подтверждения, зона загрузки, пустые
  состояния и сообщения об ошибках. Все страницы и 404 переводятся на эти компоненты.
- Таблицы статистики сортируются по клику на заголовок. Сортировка хранится в адресе страницы. Колонка
  «Игрок» закреплена при горизонтальном скролле. Rating, ADR, KAST и K/D окрашиваются по фиксированной
  шкале «плохо / средне / хорошо».
- Удаление сессии, удаление матча и пересчёт подтверждаются модальным диалогом вместо `confirm()`.
- Загрузка демок: drag&drop зона и выбор файлов, отсев неподдерживаемых форматов до отправки, файлы
  отправляются по одному по очереди с прогрессом, объёмом и оценкой времени. Можно отменить файл или
  всю очередь.
- Матчи сессии переставляются перетаскиванием за ручку на любую позицию, а с клавиатуры — стрелками.
  Кнопки ↑/↓ убираются.
- Сессии: создание в диалоге; поиск по названию и дате; группировка по месяцам; у каждого вечера видны
  карты, число матчей с ошибкой и лучший игрок по rating. Название и дата сессии правятся на месте, по
  одному полю. Пока идёт пересчёт, показывается плашка с прогрессом.
- Матч: ссылка на сессию с её названием, переход к соседним матчам («N из M»), шапки команд с исходом,
  строка сумм команды.
- Игроки и профиль: фильтры в боковой панели (на профиле — над таблицами), выбор сессий в поповере, ряд
  крупных показателей в профиле, подсветка текущего игрока или игроков из фильтра.
- Бэкенд: `GET /api/sessions` дополнительно возвращает для каждой сессии карты матчей, число матчей с
  ошибкой и лучшего игрока сессии. Поля только добавляются, совместимость сохраняется.

## Capabilities

### New Capabilities
- `web-ui`: общие правила веб-интерфейса — тёмная тема и адаптивная раскладка, таблицы статистики
  (сортировка в адресе, закреплённая колонка, шкала метрик), подтверждение необратимых и массовых действий
  в диалоге, отображение статусов обработки.

### Modified Capabilities
- `game-sessions`: список сессий получает сводку по каждой (карты, ошибки, лучший игрок), поиск и
  группировку по месяцам. Создание сессии переносится в диалог. Порядок матчей меняется перетаскиванием на
  любую позицию и с клавиатуры. Просмотр сессии показывает прогресс пересчёта.
- `demo-ingestion`: интерфейс загрузки — drag&drop, проверка формата до отправки, последовательная
  отправка по одному файлу с прогрессом и отменой.
- `match-stats`: страница матча показывает название сессии, позицию матча в ней с переходом к соседним,
  исход каждой команды и строку сумм команды. Сортировка таблиц по умолчанию — по rating.
- `player-stats`: общая таблица и разбивки профиля сортируются пользователем, сортировка хранится в адресе
  вместе с фильтрами. Профиль показывает ключевые показатели крупными плитками. Строки выбранных игроков
  подсвечиваются.

## Impact

- `web/`: новые зависимости `tailwindcss`, `@tailwindcss/vite`, `@headlessui/react`,
  `@fontsource-variable/manrope`, `@fontsource-variable/jetbrains-mono`. Новые `web/src/components/ui/*`,
  `web/src/metrics.ts`, хук сортировки. Переписываются все страницы, `PlayersTable`, `PeriodFilter`,
  `index.css`. `api.uploadDemos` вызывается по одному файлу и поддерживает отмену.
- `internal/store`, `internal/api`: расширение `ListSessions` и `SessionSummary`, тесты. Схема БД не
  меняется, `ProcessingVersion` не поднимается.
- Встроенный бинарь (`make build`) включает шрифты в бандл. Внешних запросов за шрифтами нет.
- Документация: `CLAUDE.md` (фронтенд больше не прототип, стек), `openspec/config.yaml` (контекст стека),
  `README.md` при необходимости.
- Вне объёма: светлая тема, графики и динамика по времени, аватары, авторизация.
